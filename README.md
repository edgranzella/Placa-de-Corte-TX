# Plaquetita de Corte TX - Hardware y PCB 🚀

Este repositorio contiene el diseño completo de la placa de circuito impreso (PCB) desarrollado en **KiCad** para el módulo **Plaquetita de Corte TX**. 

Este circuito está diseñado para actuar como un módulo de interrupción, conmutación o protección rápida en las líneas de transmisión (TX) o señales críticas de RF/Comunicaciones.

---

## 📌 Características del Diseño
* **Corte y Conmutación de Señal:** Etapa optimizada para la interrupción limpia de líneas de datos o transmisión sin atenuación excesiva.
* **Protección de Línea:** Incorporación de componentes de protección contra transitorios (ESD/TVS) en los terminales de entrada y salida.
* **Dimensiones Reducidas:** Diseño ultracompacto ideal para ser integrado como módulo secundario (piggyback) o en gabinetes pequeños.

---

## 🛠️ Especificaciones Técnicas de Fabricación
Configuración sugerida basada en las reglas de diseño (DRC) aplicadas en KiCad:

| Parámetro | Configuración Sugerida |
| :--- | :--- |
| **Capas (Layers)** | 2 Capas |
| **Grosor de la Placa** | 1.6 mm / 1.0 mm (si se busca menor perfil) |
| **Acabado Superficial** | HASL (with lead) o ENIG (Recomendado para señales de alta velocidad) |
